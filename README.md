## 1. Назначение программы
Программа предназначена для анализа работы облачной инфраструктуры по последовательности телеметрических измерений. На данном этапе (КТ1) реализована базовая проверка расчетов на тестовом наборе данных (5 значений) без чтения из файла.
## 2. Индивидуальный вариант
*   **Компоненты:** SSD, APP, LOG.
*   **Порядок записи:** `значение время компонент` (разделитель — пробел).
*   **Параметр k (период сравнения):** 2.
*   **Порог L:** 1.0.
*   **Производный показатель Q:** Квадрат относительного изменения.
    \[
Q[i] = \left( \frac{X[i] - X[i-k]}{X[i-k]} \right)^2
\]
*   **Правило состояния:** Если \(|Q| > L\) два измерения подряд — «ПРЕДУПРЕЖДЕНИЕ», иначе «НОРМА».
*   **Правило инцидента:** «Два из трёх». Инцидент возникает, если не менее двух компонентов одновременно находятся в состоянии, отличном от «НОРМА». Булево выражение: `Incident = (A AND B) OR (A AND C) OR (B AND C)`.
## 3. Контрольный пример и ручной расчет (КТ1)
Для проверки корректности программы был выполнен ручной расчет на тестовых значениях компонента **APP** (первые 5 отсчетов):
*   \(t_1 = 53.8\)
*   \(t_2 = 57.2\)
*   \(t_3 = 55.2\)
*   \(t_4 = 53.2\)
*   \(t_5 = 51.2\)
**Расчет (k=2):**
1.  Для \(t_3\) (i=2): \(X[2]=55.2\), \(X[0]=53.8\)
    \(Q[2] = \left(\frac{55.2 - 53.8}{53.8}\right)^2 \approx 0.000677\) (Норма, т.к. \(< 1.0\))
2.  Для \(t_4\) (i=3): \(X[3]=53.2\), \(X[1]=57.2\)
    \(Q[3] = \left(\frac{53.2 - 57.2}{57.2}\right)^2 \approx 0.004890\) (Норма)
3.  Для \(t_5\) (i=4): \(X[4]=51.2\), \(X[2]=55.2\)
    \(Q[4] = \left(\frac{51.2 - 55.2}{55.2}\right)^2 \approx 0.005250\) (Норма)
**Ожидаемый результат:** Ни одно значение \(Q\) не превысило порог \(L=1.0\). Все состояния — «НОРМА». Инцидентов нет.
