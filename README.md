## 1. Назначение программы
Программа предназначена для анализа работы облачной инфраструктуры по последовательности телеметрических измерений. На данном этапе (КТ1) реализован базовый контроль расчетов производных показателей на тестовом наборе из 5 значений без чтения из файла.
## 2. Индивидуальный вариант
Компоненты: SSD, APP, LOG

Параметры: k = 2, L = 1.0

Формат данных: значение время компонент

Формула производного показателя Q (квадрат относительного изменения):

Q[i] = ((X[i] - X[i-k]) / X[i-k])^2

Правило состояния: Если |Q| > L (1.0) два измерения подряд — «ПРЕДУПРЕЖДЕНИЕ», иначе «НОРМА».
Правило инцидента (Два из трёх):
Инцидент возникает, если не менее двух компонентов одновременно находятся в состоянии «ПРЕДУПРЕЖДЕНИЕ».
Булево выражение: Incident = (A AND B) OR (A AND C) OR (B AND C)
## 3. Ручной расчет (Контрольный пример)
Для расчета возьмем тестовые данные и упорядочим их по времени.
Поскольку по условию задания у одного компонента могут быть разные значения на одном отсчёте, все они учитываются. Поэтому для компонента LOG оба значения на 2-м и 4-м шагах записываются в общий временной ряд подряд.
### Компонент APP
t1=53.8, t2=57.2, t3=55.2, t4=53.2, t5=51.2

 t3 (i=2): Q = ((55.2 - 53.8) / 53.8)^2 ≈ 0.000677 (Норма)
 
 t4 (i=3): Q = ((53.2 - 57.2) / 57.2)^2 ≈ 0.004890 (Норма)
 
 t5 (i=4): Q = ((51.2 - 55.2) / 55.2)^2 ≈ 0.005250 (Норма)
 
### Компонент SSD
t1=43.7, t2=44.2, t3=44.7, t4=50.6, t5=51.1

 t3 (i=2): Q = ((44.7 - 43.7) / 43.7)^2 ≈ 0.000523 (Норма)
 
 t4 (i=3): Q = ((50.6 - 44.2) / 44.2)^2 ≈ 0.020960 (Норма)
 
 t5 (i=4): Q = ((51.1 - 44.7) / 44.7)^2 ≈ 0.020500 (Норма)
 
### Компонент LOG
t1=32.0, t2=33.6, t2=31.3, t3=30.6, t4=35.2, t4=37.5, t5=34.5

i=2 (31.3): Q ≈ 0.000478 (Норма)

i=3 (30.6): Q ≈ 0.007970 (Норма)

 i=4 (35.2): Q ≈ 0.015520 (Норма)
 
 i=5 (37.5): Q ≈ 0.050840 (Норма)
 
i=6 (34.5): Q ≈ 0.000395 (Норма)

Ожидаемый результат:
Ни одно значение Q не превысило L=1.0. Все состояния — «НОРМА» (0). Правило «Два из трёх» не срабатывает. Инцидентов нет.
