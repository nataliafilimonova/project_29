## 1. Назначение программы

Программа на языке C предназначена для анализа телеметрических измерений компонентов облачной инфраструктуры. На первом этапе реализована базовая проверка расчетов производных показателей на тестовом наборе из 5 значений без чтения из файла.

## 2. Индивидуальный вариант

##Вариант: 29.
Компоненты: SSD, APP, LOG.

Порядок записи измерения: значение → номер отсчёта → код компонента.

Разделитель полей и записей: пробел.

Тип последовательности: у одного компонента могут быть разные значения на одном отсчёте; учитываются все измерения.

Производный показатель Q: квадрат относительного изменения.

Параметры: k = 2, L = 1.0.


$$
Q[i] = \left( \frac{X[i] - X[i-k]}{X[i-k]} \right)^2
$$

Правило состояния компонента:
Если |Q| > L (1.0) два измерения подряд — «ПРЕДУПРЕЖДЕНИЕ», иначе «НОРМА».

Правило инцидента (Два из трёх):
Инцидент возникает, если не менее двух компонентов одновременно находятся в состоянии «ПРЕДУПРЕЖДЕНИЕ».

Булево выражение: (A != 0) && (B != 0) || (A != 0) && (C != 0) || (B != 0) && (C != 0)

## 3. Описание компонентов

Входные данные используют три кода компонентов:
APP
SSD
LOG

## 4. Формат исходных данных

Измерения записываются в одну строку, разделяются пробелами и повторяются в следующем порядке:
значение номер_отсчёта код_компонента

Значение — вещественное число, номер отсчёта — целое число (порядковый номер замера), код компонента — один из кодов APP, SSD, LOG.

## 5. Ручной расчет (5 значений)

Для расчета возьмем 5 значений каждого компонента, упорядочив их по времени. Так как k = 2, показатель Q рассчитывается начиная с 3-го отсчета.

Значения по времени:

APP: 1) 53.8, 2) 57.2, 3) 55.2, 4) 53.2, 5) 51.2

SSD: 1) 43.7, 2) 44.2, 3) 44.7, 4) 50.6, 5) 51.1

LOG: 1) 32.0, 2) 33.6, 3) 30.6, 4) 35.2, 5) 34.5

Ручной расчёт (при k = 2, L = 1.0):

Отсчёт 3 (пара с отсчётом 1):

APP: Q = ((55.2 - 53.8) / 53.8)^2 = (1.4 / 53.8)^2 ≈ 0.000677 — НОРМА

SSD: Q = ((44.7 - 43.7) / 43.7)^2 = (1.0 / 43.7)^2 ≈ 0.000523 — НОРМА

LOG: Q = ((30.6 - 32.0) / 32.0)^2 = (-1.4 / 32.0)^2 ≈ 0.001914 — НОРМА

Инцидента нет.

Отсчёт 4 (пара с отсчётом 2):

APP: Q = ((53.2 - 57.2) / 57.2)^2 = (-4.0 / 57.2)^2 ≈ 0.004890 — НОРМА

SSD: Q = ((50.6 - 44.2) / 44.2)^2 = (6.4 / 44.2)^2 ≈ 0.020960 — НОРМА

LOG: Q = ((35.2 - 33.6) / 33.6)^2 = (1.6 / 33.6)^2 ≈ 0.002267 — НОРМА

Инцидента нет.

Отсчёт 5 (пара с отсчётом 3):

APP: Q = ((51.2 - 55.2) / 55.2)^2 = (-4.0 / 55.2)^2 ≈ 0.005250 — НОРМА

SSD: Q = ((51.1 - 44.7) / 44.7)^2 = (6.4 / 44.7)^2 ≈ 0.020500 — НОРМА

LOG: Q = ((34.5 - 30.6) / 30.6)^2 = (3.9 / 30.6)^2 ≈ 0.016226 — НОРМА

Инцидента нет.

Ожидаемый результат:

Ни одно значение Q не превысило L = 1.0. Все состояния — «НОРМА». Правило «Два из трёх» не срабатывает. Инцидентов нет.
